# Java EE para calcular intereses

## 1. Instalar dependencias necesarias para crear archivo .log

### 1.1 Ir al sitio de descargas **https://logging.apache.org/log4j/2.x/download.html** y descargar las dependencias necesarias para generar el log a partir de un archivo xml, las dependencias .jar necesarias son:

  - log4j-api-2.x.x.jar
  - log4j-core-2.x.x.jar

### 1.2 Una vez descargadas las dependencias, se tendrán que colocar dentro de la carpeta **WEB-INF/lib** y después hay que recargar el proyecto
